## 为什么可信

- **数据透明**：排名基于公开快照，不做黑箱推荐
- **证据先行**：质检报告每一条结论都带可复核的证据
- **社区共建**：目录条目走 PR，任何人可补充、可纠错

## 参与贡献

- 提交一个 CLI：阅读 [CONTRIBUTING](./supercli/CONTRIBUTING.md)，发 PR 即可
- 给项目做质检：`scorecard` 支持 GitHub 仓库、npm 包、在线网页三种目标
- 从零开始学：跟着[小白看板](https://xiaobai.supercli.site)一步步让 Agent 帮你写代码
- 报告问题：各仓库 Issues 均开放
